# viral-reel-generator

Videos "copycat": una persona ya grabada + infografías, subtítulos animados, mapas y gráficas financieras animadas, con la línea gráfica de MacroWise.

## Línea gráfica (aplica a TODOS los videos)
- Fondo Warm Black `#1A1A17`, tarjetas `#232320`, texto `#D6D1C8`. Tarjetas siempre opacas.
- Geist 600 (tracking -0.03em) y Geist Mono 700 (tracking 0.18em).
- Subtítulos blancos con sombra suave, palabra clave en verde lima `#C6DD2E`, como pista editable (nunca quemados).
- Datos por taxonomía: oro `#C9A84C` valor · teal `#50B5A2` técnico · púrpura `#73247D` geopolítica · terracota `#C44A33` costes.
- Sin neón, glow ni degradados. Máster 9:16.

## Herramientas
- Infografías y subtítulos: HyperFrames (Remotion solo si hace falta).
- Mapas: Electric Eye. Gráficas de precios animadas: Ride the Lightning.
- Entregables: overlays ProRes 4444 con alfa + MP4 de referencia + subtítulos .srt.
